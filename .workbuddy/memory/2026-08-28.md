### 关键结论 / 约定
- 爬虫接口：`https://webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry?gameNo=85`（gameNo=85 大乐透），返回 `value.list[].lotteryDrawNum/lotteryDrawResult/lotteryDrawTime`，`lotteryDrawResult` 格式 "前区5码 后区2码" 空格分隔。pageSize 上限约 100，total 约 2915 期。需带 User-Agent + Referer 头。
- 前区三区划分：1-12 / 13-24 / 25-35。
- 统计维度：空间分布 / 前区奇偶 / 跨度 / 重号 / 连号 / 后区奇偶，各含理论概率与回归周期（硬编码在 StatisticsService）。
- 推荐策略：前 3 注「概率最大 + 回归期望（连号/重号欠回归动态命中）」，后 2 注「最冷号（最近 30 期频次最低）+ 回归期望 + 概率最大」。
- 后端已用 JDK 21（/opt/homebrew/opt/openjdk@21）+ 阿里云镜像验证编译通过。本机无默认 Java（/usr/bin/java 是 stub），需手动设 JAVA_HOME。
